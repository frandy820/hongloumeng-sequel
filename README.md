# 红楼梦·续后四十三回

> 如果曹雪芹的八十回之后，不是我们现在读到的那四十回呢？

一部**承接原著前八十回脂本脉络**的非官方续书：跳过程高本，从第八十一回写起，至第一百二十三回收束，共 **43 回 · 约 35 万字**，二轮文学精修版。

---

## 为什么值得一读

- **不接程高本，接脂批**。迎春误嫁中山狼、抄检大观园后的树倒猢狲散、宝玉宝钗的"齐眉举案"、黛玉的泪尽、香菱的结局、雨村的下场——这些前八十回埋下、脂批点过的伏笔，在这里一条一条落地，而不是"兰桂齐芳"的大团圆。
- **章回体的老味道**。回目对仗、话说且说、雪泥半融的紫菱洲、药炉边一部《王摩诘全集》——行文向原著白话章回靠拢，力求"像那个时代的字"。
- **写败落，也写人心**。索银的门房、当掉的皮袄、月例里匀出来的一份——贾府的塌不是一声巨响，是一笔一笔的账。
- **回目即剧透，正文即人情**。如第八十一回：紫菱洲宝玉悲摇落，潇湘馆黛玉检诗笺——从迎春归宁写起，一开篇就是原著停笔处的寒意。
